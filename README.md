# Пульт для защиты диплома

Читалка PDF-презентации с приколами поверх слайдов, которые жюри запускает с телефона.

- **Экран:** `index.html`. Его открывает ведущий в Chrome и показывает в Зуме.
- **Пульт:** `remote.html?room=XXXX`. Жюри открывает его по QR-коду с экрана или вводит код вручную.

Всё, что показывается во время защиты, загружается заранее, на стартовом экране. Во время показа из сети ничего не подгружается.

## Запуск локально

```bash
npm install
npm run dev          # http://localhost:5195 , пульт — по ссылке из QR или ?debug → «Открыть пульт»
npm run build        # сборка в dist/
```

`?debug` на экране включает лог событий, кнопку «Открыть пульт в новой вкладке» и симуляцию жюри (клавиша **J**).

Пока Firebase не настроен, экран и пульт связываются через вкладки одного браузера. С телефона пульт в этом режиме не заработает.

## Ассеты и конфиг

Все тексты, списки и пути к файлам лежат в `public/config.json`. Сейчас там заглушки, которые сгенерировал `npm run placeholders`.

| Что | Куда положить | Поле в config.json |
|---|---|---|
| Презентация | `public/assets/presentation.pdf` | `pdf` |
| Обложка команды для плеера | `public/assets/cover.jpg` | `player.cover` |
| Мемы (png/gif/webp/svg, до ~1 МБ) | `public/assets/memes/` | `memes[]` |
| СДВГ-ролики (mp4 H.264, вертикальные, до ~20 МБ) и превью для пульта (jpg) | `public/assets/videos/` | `videos[]` (`file`, `poster`) |
| Музыка жанров | `public/assets/genres/<id>/music.mp3` | `genres[].music` |
| Свои украшения жанра (PNG с прозрачностью) | `public/assets/genres/<id>/` | `genres[].decor: {"top": …, "left": …, "right": …}` |
| Песни для гачи и обложки | `public/assets/gacha/` | `gacha[]` (`rarity`: common / rare / legendary, `weight`: вес выпадения) |

Другие настройки:

- `player.durationSec`: длительность защиты (420 = 7:00).
- `player.warnAtSec`: с какой секунды полоса таймера становится оранжевой.
- `player.autostart`: таймер стартует сам при уходе с первого слайда.
- `gachaFromSlide`: с какого слайда (с 1) открывается гача; `null` — с последнего.
- `startGenre`: id жанра, который включится сразу; `null` — без украшений, пока жюри не встряхнёт.
- `tickerLoops`: сколько раз пробегает бегущая строка.
- `volume.genre`, `volume.gacha`: громкость музыки.

Встроенные SVG-украшения: `svg:cozy`, `svg:gothic`, `svg:racing`, `svg:rave`, `svg:country`.

Если файла из конфига нет, приложение не падает: пишет предупреждение в консоль, а в режиме `?debug` ещё и в лог на экране.

**PDF в последний момент:** если финальная версия пришла перед самой защитой, ведущий просто перетаскивает файл в окно экрана, передеплой не нужен. После перезагрузки страницы вернётся PDF с сайта.

## Настройка Firebase (один раз, ~5 минут)

1. Открыть [console.firebase.google.com](https://console.firebase.google.com) → «Создать проект» (Google Analytics не нужен).
2. Слева **Build → Realtime Database → Create Database**. Регион — `europe-west1`, режим — **locked**.
3. Вкладка **Rules** — вставить и нажать **Publish**:

   ```json
   {
     "rules": {
       ".read": false,
       ".write": false,
       "rooms": {
         "$code": {
           ".read": "$code.length === 4",
           ".write": "$code.length === 4",
           "events": {
             ".indexOn": ["t"],
             "$id": { ".validate": "newData.child('ev/type').isString() && newData.child('from').isString()" }
           }
         }
       }
     }
   }
   ```

   У этих правил нет срока годности, в отличие от «тестового режима» на 30 дней. Доступ есть только к комнатам из 4 символов.
4. **Project settings** (шестерёнка) → **Your apps** → иконка `</>` → зарегистрировать веб-приложение (Hosting не нужен).
5. Скопировать объект `firebaseConfig` в `src/firebase-config.ts` вместо `null`:

   ```ts
   export const firebaseConfig: FirebaseOptions | null = {
     apiKey: '…',
     authDomain: '….firebaseapp.com',
     databaseURL: 'https://…-default-rtdb.europe-west1.firebasedatabase.app',
     projectId: '…',
     appId: '…',
   };
   ```

   Без `databaseURL` не заработает: проверьте, что он есть.
6. Закоммитить и запушить: GitHub Actions пересоберёт сайт.

Ключи в конфиге не секретные, это нормально для веб-приложений Firebase. Доступ ограничивают правила базы.

**Если Firebase не открывается у жюри**, вся связь живёт в `src/transport.ts` (интерфейс `Transport`). Новый транспорт — это ещё один файл рядом и строка в `createTransport`. `?transport=local` принудительно включает связь через вкладки.

## Деплой на GitHub Pages

Settings → Pages → Source: **GitHub Actions**. Дальше каждый пуш в `main` собирает и публикует сайт (`.github/workflows/deploy.yml`). Пути относительные, сайт работает из любой подпапки.

## Горячие клавиши ведущего

Работают в любой раскладке. **H** на экране показывает эту же подсказку.

| Клавиша | Действие |
|---|---|
| → ← / PgDn PgUp / Пробел / Enter | слайды (кликеры тоже работают) |
| Home / End | первый / последний слайд |
| T / R | таймер: старт-пауза / сброс |
| M | случайный мем |
| S | встряхнуть (следующий жанр) |
| V / Shift+V | убрать СДВГ-ролик / случайный ролик |
| K | случайная фраза в бегущую строку |
| G / Shift+G | открыть гачу жюри / крутить самому |
| F | итоги (ещё раз F — закрыть) |
| [ ] 0 | музыка тише / громче / выкл-вкл |
| X | выключатель пульта: события игнорируются, на пульте плашка «Ведущий поставил на паузу» |
| C или Backspace | убрать всё лишнее: мемы, строку, ролик, QR |
| Q | показать QR |
| H | подсказка |
| Shift+R | начать показ с нуля (сброс таймера, статистики, жанра, гачи; код комнаты остаётся) |

Экран запоминает своё состояние: слайд, таймер, статистику, жанр и гачу. Если случайно нажать F5, показ продолжится с того же места, и пульты переподключать не нужно.

## Чек-лист перед защитой

- [ ] Пульт открывается с телефона по **мобильному интернету** и по **Wi-Fi**. Зарубежные сервисы в России могут работать нестабильно. Если Firebase не открывается, меняем транспорт (см. выше). Горячие клавиши работают в любом случае.
- [ ] Ведущий открывает ссылку в **Chrome** и ждёт, пока загрузятся все файлы, потом жмёт **«Начать показ»**. Эта кнопка включает полный экран и разрешает звук. F11 не нужен: на Mac он не работает.
- [ ] В Зуме: «Демонстрация экрана» → **весь экран** (не окно Chrome) → отметить **«Совместное использование звука»**. Без этого гача и музыка жанров не будут слышны. На Mac при первом включении Зум ставит аудиодрайвер и просит пароль администратора, так что сделайте это заранее.
- [ ] Ведущий в **наушниках** или с выключенным микрофоном, иначе музыка из динамиков попадёт в микрофон и будет эхо.
- [ ] На тестовом созвоне проверить галочку **«Оптимизировать для видеоклипа»**. С ней анимации и ролик плавные, но текст слайдов мягче. Без неё текст чёткий, но анимации дёргаются. Выберите, что лучше.
- [ ] Громкость фона проверена на тестовом созвоне: голос спикера разборчив. Если нет — `[` и `]`.
- [ ] Ноутбук на зарядке, уведомления выключены (режим «Не беспокоить»). Сон экран сам блокирует, пока вкладка открыта.
- [ ] Ведущий знает про **H** (подсказка), **X** (выключить пульт) и **C** (убрать всё с экрана).
- [ ] Перед защитой: **Shift+R**, чтобы сбросить статистику после репетиций.
- [ ] На всякий случай PDF открыт и в обычной программе просмотра.
